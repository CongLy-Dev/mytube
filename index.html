Cài Đặt YouTube Data API Key

Nhập mã YouTube Data API v3 Key để tải danh sách, tìm kiếm và xem thông tin kênh. Khóa API không điều khiển trình phát hoặc chất lượng video. Khóa được lưu trong trình duyệt Safari trên iPad 4 của bạn.

Nếu muốn gắn key sẵn trong file, dán vào biến EMBEDDED_API_KEY ở đầu phần JavaScript. Không chia sẻ file chứa key; hãy giới hạn key trong Google Cloud Console.

* Hướng dẫn: Bạn có thể lấy API Key miễn phí từ Google Cloud Console bằng cách bật dịch vụ "YouTube Data API v3".
